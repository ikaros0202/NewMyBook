# 新阅 UI 设计系统

状态：1.0.2 第二版，参考 Apple Books 的精致书籍感。首版灰绿视觉稿已被用户否决，不作为验收依据。界面服务于本地小说阅读；用户选择的正文配色和字体与工具页风格分开管理。

## 设计方向与参考

- 用户明确要求重做配色、默认小书封、字体与设置布局。工具界面使用白色和中性浅灰，深色文字，暖橙仅用于必要动作和状态；避免整片有色表面。
- 视觉参照 [Apple Books 官方展示](https://www.apple.com/apple-books/) 的书籍主导和清楚的阅读控制；不复制书店、推荐、账号或云能力。
- 本项目禁用 oiloil-ui-ux-guide，后续设计不得调用、读取或以它为指导。
- 正文保留纸白、米黄、护眼、深灰、OLED 黑及用户自定义配色。暗色阅读时，菜单、弹窗与设置也使用深色工具表面。
- 指导项目：[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)，参考提交 `09170eec67eefd46a7ae85de61b40c194020f997`。2026-09-29 核实 131,398 Star，2026-09-27 有更新；原始查询保存在 `qa/current/1.0.2/design-reference.json`。
- 采用其可预测返回、移动端触控尺寸、可发现状态、减少拖动依赖等原则；结合真实模拟器截图进行取舍，不把网页营销布局移植到阅读器。
- 封面允许细书脊和轻微阴影，用排版和线纹表现书籍感；不用玻璃模糊、阴影卡片墙、巨大宣传区或无意义动画。图标使用矢量资源。

## 信息层次和按钮判断

1. 正文与续读最优先；阅读时隐藏工具，点击后稳定显示。
2. 目录、搜索、朗读、外观、笔记具有明确图标和短标签。
3. 快捷设置只放作用域、字号、背景和亮度；低频排版、主题管理和更多行为进入完整设置。
4. 同一对象的管理动作收进该对象的更多菜单；一个动作不同时占用整行点击和额外确认按钮。
5. 关键提交只有一个明确入口：设置保存、进度跳转、导出确认。取消不提交草稿。
6. 危险操作说明影响和可恢复边界；技术校验细节放在可展开详情中。
7. 合理页面保持简单，不为了统一模板给每个入口套卡片。

## 字体与尺寸

- 常规页标题 20–22sp，主页面标题最高 30sp；区块标题 16sp / 24sp，字重以 Regular / Medium 为主，减少粗黑字堆叠。书封使用独立的完整书名排版，不能截取四个汉字替代原书名。
- 正文说明 14sp / 20sp；辅助说明 12sp / 17sp。阅读正文由用户阅读设置决定。
- 间距以 4dp 为基准，常用 8 / 12 / 16 / 24dp；手机页面水平内边距 16dp。
- 动作触控区域至少 48×48dp。可见图标通常 20–24dp，滑杆采用 4dp 细轨道和小圆拇指，实际触控高度仍为 48dp。
- 数字类排版用紧凑步进与可输入精调，保留原范围、步长和设置精度；单项重置收进编辑窗口。亮度等连续调节保留细滑杆。主题开始时间使用跟随当前主题的中文时间窗口。
- 圆角 4 / 8 / 12 / 16dp；分隔线、留白优先于大型背景块。

## 页面规则

- **书架**：取消网格与列表阅读进度条，保留紧凑进度文字；增大书封，网格书名独占全宽，不被菜单挤压。书名、封面和续读状态优先；两/三/四列密度只在网格模式显示。书籍菜单提供“选择”，搜索中选择会退出搜索并显示选择栏。集合、状态操作分别收进批量菜单，删除保持明确入口。
- **主导航**：底部 72dp，同时显示图标与“书架 / 统计 / 设置”。统计使用柱形图标；宽屏保留侧边导航。
- **阅读外观**：快捷页使用 A− / 当前字号 / A+、五种圆形真实背景色样、亮度及跟随系统；标题栏保存/取消。完整设置的分区入口清楚可达，滚动内容有统一边距。
- **主题**：整行选择应用，色样显示真实前景/背景；复制、重命名、更新、删除进入更多菜单。日间、夜间主题用下拉列表选择。
- **行为与时间**：九宫格使用连续 3×3 区域示意，每格标明位置和当前动作；不做九个独立胶囊按钮。时段输入使用中文“时 / 分”，显示范围并拒绝非法数值，取消保持原值。
- **阅读工具**：章节管理每行一个更多菜单；选择工具条用四个颜色圆点，书签/批注保留文字，空间不足换行。正文搜索不常驻显示“重建索引”；错误时提供恢复入口。取消进度滑杆；目录选章与全书页码输入分别可达，按当前版式计算精确全书页码，点击“跳转”才提交续读位置。
- **设置主页**：浅灰页底、白色分组列表和细分隔线；分组标题使用次文字色，七个能力入口保持可达。
- **统计**：空状态不绘制无意义零值图和空排行；已有会话但有效时长为零明确说明。单书统计有顶部返回箭头和正确的系统返回。周期选择保持紧凑。
- **导入**：默认自动识别编码；手动编码是次级入口。完成批次隐藏进度条，成功项直接开始阅读；重复、失败仍提供具体处理动作。
- **备份与恢复**：按整个书架、笔记与单书分组；备份/恢复/批注/接力每项一个明确入口。导出先选格式、再点一次导出；恢复先看数量、影响与空间，格式/暂存详情可展开。

## 验证使用方式

按当次改动核查截图、关键交互、窄屏/大字与深色状态；不把本页当作每轮全量测试清单。具体已验证设备、页面、方法和未覆盖边界由对应 `qa/` 记录，不以设计目标冒充测试结论。
