# 新阅 UI 设计系统

状态：基线 1.0.0 的当前设计真相源。页面级文件可覆盖本文件，但不得破坏无障碍、离线和正文优先边界。

## 产品气质

- 关键词：纸页、墨色、目录、安静、清晰、克制、紧凑、书库优先。
- 参考方向：Anx Reader 的真实书架首页骨架、编辑出版物的目录层级、Android 原生交互语义。
- 不采用：实时玻璃模糊、渐变大卡片、重复圆形光晕、装饰性阴影、双层胶囊、营销页式 Hero、在线字体、Emoji 图标和无意义入场动画。
- 应用标题、区块标题和书名使用 Android 可用的系统 Serif 族制造纸页索引气质；按钮、辅助信息和正文阅读继续使用平台可读字体与阅读器已有字体/导入字体设置。

## 信息层级

1. 找到或继续一本书：书架默认按真实最近打开排序，一次点击恢复稳定位置。
2. 浏览书库：封面网格、搜索、状态筛选和持久密度偏好。
3. 阅读中操作：目录、进度、外观、搜索、朗读、书签/笔记。
4. 整理书库：作者、系列、集合、排序、批量管理。
5. 低频配置与数据：高级排版、字体、主题计划、统计、备份恢复。

功能不得因降级视觉权重而消失；低频功能使用渐进披露。

## 颜色角色

颜色只在 `XinYueTheme` 中定义；页面必须使用 `MaterialTheme.colorScheme` 语义角色。

| 角色 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| primary | `#8B3F32` | `#D18472` | 主动作、进度、当前状态 |
| onPrimary | `#FFFFFF` | `#4A211A` | 主色上的内容 |
| primaryContainer | `#EBD0C9` | `#6E3027` | 低强度选中/继续阅读 |
| secondary | `#756E63` | `#B7AFA2` | 次级信息 |
| secondaryContainer | `#E4DDD2` | `#4A443C` | 纸页中性容器 |
| background / surface | `#F3EEE3` | `#1C1A17` | 纸页/墨色基底 |
| surfaceContainerLow | `#EFE8DC` | `#24211D` | 仅用于确有边界的工具表面 |
| surfaceContainer | `#E9E1D5` | `#2B2722` | 控制层 |
| onSurface | `#28241E` | `#EEE8DC` | 主文字 |
| onSurfaceVariant | `#756E63` | `#B7AFA2` | 次文字 |
| outline / outlineVariant | `#70685B` / `#CFC6B7` | `#9D9387` / `#49433B` | 交互边框 / 分隔线 |
| error | `#BA1A1A` | `#FFB4AB` | 删除与错误 |

浅色小字对背景至少 4.5:1；图标和大字至少 3:1。状态不能只靠颜色表达。

## 字体层级

- 页面标题：`headlineSmall`，24sp / 30sp，系统 Serif，600。
- 区块标题：`titleMedium`，16sp / 22sp，系统 Serif，600。
- 书名：`titleSmall` 或 `labelLarge`，14sp / 20sp，最多两行；长标题溢出省略。
- 正文与说明：`bodyMedium`，14sp / 20sp；辅助信息 `bodySmall`，12sp / 17sp。
- 标签：`labelMedium`，12sp / 16sp，500；作者、状态和进度最多一行。
- 阅读正文继续由阅读器外观设置决定，不把应用壳字体选择写入正文内容。

## 间距、尺寸与形状

- 基线：4dp；常用间距：4 / 8 / 12 / 16 / 24dp。
- 页面水平边距：紧凑手机 16dp；中/大宽度自适应增加。
- 顶栏：56dp；阅读控制行：56dp；设置行：最小 64dp；紧凑书架行目标 80–88dp。
- 交互命中区：Android 至少 48×48dp；可见图标通常 20–24dp。
- 圆角：小 4dp、中 8dp、大 12dp、强调容器 16dp；底栏和分隔线页面不使用胶囊容器。
- 深度优先使用距离、纸页色阶和分隔线；禁止为了“精致”给每个入口加阴影或背景卡。

## 页面规则

### 书架首页（默认根标签）

- 顶栏把“书架”和搜索入口放在同一行，右侧为导入、排序/布局；下一行只有轻量文字状态筛选和集合入口。
- 默认标准三列封面网格；舒适两列、紧凑四列和紧凑列表均为持久的一等模式。
- 首个真实最近在读卡显示小型“继续”标记；不使用大 Hero。
- 列表突出书名、作者/系列、进度；字符集和字符数不进入常规卡片。
- 网格突出封面、两行书名和进度；大字体自动降列。
- 手机使用 72dp 高、无外框胶囊的图标底栏，图标保持 48dp 命中区；宽屏使用 NavigationRail。
- 默认封面采用平面纸色、细边和书名排版，不使用渐变或圆形光晕；真实自定义封面仍优先。

### 设置

- 使用目录式分组列表，分组标题、留白和细分隔线表达层级，不把每组或每个入口做成大型彩色卡。
- 分组为“常用阅读”“个性化”“信息与本地数据”；全部七个现有入口保留。

### 统计

- 日/周/月周期选择放在“每日有效阅读”标题同一行的末端，使用轻量文字与短下划线；不在摘要和图表之间单独占用一整行。
- 每日有效阅读图表固定 184dp 高度，使用最多七个等宽连续日期桶；柱高表达有效阅读时长，刻度、柱顶时长和无障碍日期/会话语义同时保留。
- 总时长、图表和书籍排行使用连续纸页排版；排行以细分隔线分隔，只有真实可进入的单书项保留点击语义。

### 阅读器

- 正文默认沉浸；控制层按需显示。
- 顶部保留返回、书名、书签、更多；底部保留目录、搜索、朗读、阅读外观、笔记。
- 图标与短标签共同提高发现性；进度行和操作行合计不得形成压迫正文的大面板。

## 动效与状态

- 仅使用 150–280ms 的状态/位置连续性动效；减少动态效果时功能完整。
- 加载不得清空既有布局；禁用、选择、错误、空态和无结果状态必须显式。
- 压下反馈不能改变布局边界。

## 交付检查

- 浅色、深色、360dp、小屏、横屏和 200% 字体均无裁切/遮挡。
- 360×800dp：标准三列网格至少完整显示 6 本，紧凑四列至少显示 8 本带书名条目，紧凑列表至少完整显示 6 本。
- 所有图标动作有中文语义；全部触控目标至少 48dp。
- 无默认 Material 紫色泄漏、硬编码页面颜色、Emoji 图标、在线字体或网络资源。
- 阅读器正文、原始 TXT、UTF-16 偏移、进度和隐私契约不因视觉改版改变。
