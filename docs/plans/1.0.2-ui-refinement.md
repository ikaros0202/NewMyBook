# 1.0.2 全页界面与阅读节奏整理

用户要求从重度本地小说读者的角度逐页审查入口、层次、可辨识性、舒适度和功能可达性，并允许本版整体更换界面风格。2026-09-29 用户否决了首版浅色中性灰绿视觉稿；首版 after 截图只作为迭代证据，不构成验收结论。用户随后明确选择接近 Apple Books 的精致书籍感，重点重做灰绿配色、默认小书封、字体和设置布局。首版截图已移至 `qa/current/1.0.2/iterations/01-rejected/`，新方案重新采集 `after/`。已对齐的功能修复以及自动翻页、定时停止仍保留在本版范围内。阅读页继续保持安静、沉浸和可恢复；页面不需要统一套用卡片模板，具体层次由页面任务决定。

本版在界面整理之外确认加入两项阅读节奏能力：自动翻页和定时停止。它们属于阅读器的直接行为，不再作为“后续发现”记录；本计划同时覆盖实现、精准验证和真实设备验证。

## 已确认的新增能力

### 自动翻页

- 提供 `10 秒 / 15 秒 / 20 秒 / 30 秒 / 60 秒` 五档间隔，默认值为 `20 秒`。
- 自动翻页运行期间，用户触摸、打开阅读菜单、应用进入后台、离开阅读页、到达书末或发生翻页/正文失败时立即暂停。
- 暂停后恢复只从当前稳定状态继续，不补发已经错过的翻页，不因为后台停留或失败重试而连续快进。
- 自动翻页属于当前阅读会话行为；暂停、恢复和失败反馈必须可理解，不能改变用户长期阅读设置。

### 定时停止

- 提供 `15 分钟 / 30 分钟 / 60 分钟` 三档停止时间。
- 计时到期后停止自动翻页和 TTS，并临时解除本次阅读会话的亮屏保持；不修改长期亮屏、自动翻页或 TTS 设置。
- 定时停止发生前后都保留已经产生的阅读进度；计时结束、离开阅读页或失败时不得丢失已保存进度。
- 定时状态属于当前阅读会话，重新进入阅读器不应把本次剩余计时伪装成长期偏好。

## 界面整理重点

- 快速设置只承载作用域、字号、五种主题、全局亮度和“更多设置”；字体、行距、段距、缩进、翻页方式和主题计划继续在完整设置中可达。
- 快速设置与完整设置共享同一份外观草稿，保存或取消明确结束编辑；当前书作用域隐藏全局亮度并说明原因。
- 阅读菜单按顶部导航/更多操作和底部高频操作重新分组；取消进度滑杆，使用“目录选章＋全书页码跳转”。全书页码按当前实际版式按需计算，不使用字符比例估算；输入合法页码后点击“跳转”才提交续读位置，并保留返回跳转前的位置。计算可取消；失败保持原文与进度。
- 书架列表与网格均取消阅读进度条，只保留简洁的进度文字；增大书封，书名独占一行或两行，菜单不挤压书名。`2026-09-29` 用户明确确认全书页码跳转，不采用本章页码或百分比输入。
- 书架搜索结果进入“选择”或长按选择时先退出搜索，再显示书架选择栏；统计单书状态提供顶部返回箭头和系统返回回到全部统计；会话存在但有效时长为零时显示明确空状态。
- 备份页面按“整个书架”和“笔记与单书”列出备份恢复、批注导出和单书接力功能；继续使用系统文件选择器完成输入输出。
- 真实页面截图用于发现层次和文案问题；不把截图数量当作自动测试数量，也不把系统页面误写成应用实现。
