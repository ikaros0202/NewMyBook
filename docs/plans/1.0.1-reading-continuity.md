# 1.0.1 计划：连续阅读体验

日期：2026-09-29。状态：实施及定向验收完成。问题来自 1.0.0 源码与 API 37 16 KB 模拟器实测；本轮修复构建标识为 1.0.1 / 9，暂不发布。结果见 [1.0.1 验收记录](../../qa/current/1.0.1/README.md)。

目标：让读者从导入到连续翻页、换章、夜间调整和下次续读都少受打断。用户已确认主要使用左右滑动翻页；目录选章直接成为续读位置，并保留返回跳转前的机会。搜索结果、书签等回看入口继续使用临时浏览。

## 实际问题与优先级

完整环境、复现步骤和原始截图见[体验记录](../../qa/current/2026-09-29-reader-experience/README.md)。以下是本次实际遇到的问题；候选技术原因不等于已确认根因。

| 编号 | 优先级 | 实际现象与读者影响 | 1.0.1 目标 |
|---|---|---|---|
| R1 | P0 | 默认 20sp、1.60 倍行高下，页底正文被截断；左滑后从更后的文字开始，导致漏读。逻辑文本边界连续，不代表屏幕显示完整。 | 分页测量与实际显示一致，分配给当前页的正文完整可见，前后翻页无漏字、重字。 |
| R2 | P1 | 从目录跳到第三章并继续翻页，书架正式进度仍为第一章 8%；同进程可回到临时页，进程重启后回到第一章。 | 目录选章立即进入正式阅读，不再额外点“从这里继续”；支持回到跳转前。 |
| R3 | P1 | “阅读外观”面板很长，夜间主题与亮度在首屏之外；调整时大部分正文被遮住。深色正文下目录和操作面板仍是大面积浅色。 | 高频调整在首屏可达，保留正文预览；阅读内工具随当前阅读主题采用合适的明暗配色。 |
| R4 | P2 | 打开阅读菜单后停下来辨认选项，约 4 秒自动收起；实测等待 5 秒后菜单已消失。 | 主动打开的菜单等待用户选择，通过明确操作关闭。 |
| R5 | P2 | 导入成功页只有编辑信息等操作，点击成功书目不能打开正文；必须返回书架再找刚导入的书。 | 每条成功结果提供“开始阅读”，导入与阅读连起来。 |

P0 表示本次版本首先解决的核心阅读缺陷；P1 为直接影响连续阅读的交互问题；P2 为低风险路径简化。五项均纳入本次计划，按下面四个可独立验证的步骤推进。

## 实施顺序与验收

### A. 先解决正文可见性（R1）

先使用本轮公开小说、相同屏幕和默认设置建立失败复现。下面的公开夹具回归仅针对分页/渲染改动，不是其他修改的例行要求。比较分页器与真实 TextView 的宽高、行数、末行底部和行距，而不只检查文本偏移是否连续。重点排查断行策略、CJK 字体行距、标题样式、页面片段末尾换行和占位符的测量差异。

确认原因后，在共享排版参数与页面测量/渲染链路内做最小修复。当前定位入口为 `AndroidTextPaginator.kt`、`ReaderPageSurface.kt`、`ReaderStyledTextFactory.kt` 与 `ReaderScreen.kt`。原文偏移与选择映射继续可靠，不以裁掉原文或随意少排若干行掩盖问题。

验收：

- 同一公开小说前三章逐页左右滑动：页面实际末行完整可见，下一页正确接续；反向翻页回到同一段落。
- 同时检查真实 TextView 的末行可见边界及截图，不能只用 UI XML 包含正文作为通过依据。
- 覆盖默认字号/行距、一个较大字号与行距组合；包括章节标题页、长段落、段落内分页和换行处分页。
- 调整排版后仍能找到当前阅读段落；受影响的原文选择/复制映射验证正确。
- 如果修复改变分页边界、布局缓存或位置恢复，选择一个仓库外私人长篇进行连续翻页与续读回归；证据只保留脱敏结论。

### B. 让目录跳转符合续读习惯（R2）

目录选择与回看导航分开表达意图：目录选章成功后，立即把所选章节写为正式续读位置，后续滑动继续更新；用户已确认“返回跳转前”放在阅读菜单中，不常驻正文底部，点击后画面和正式续读位置一起回到此次目录跳转前的位置。搜索、书签仍临时浏览，只有明确选择“从这里继续”才提交该回看位置。用户进一步确认：如果从临时浏览位置打开目录换章，“返回跳转前”回到此前正式阅读位置，临时位置不被提升为续读进度。

优先复用 `ReaderNavigationController`、`ReaderViewModel` 与现有进度写入机制。预计不需要数据库或备份格式变更；实施时以实际依赖为准。

验收：

- 从第一章跳第三章并左右翻页，回书架后显示新进度；重启进程再次打开仍在新位置。
- 目录选章后不翻页，正常离开并重启，也恢复到所选章节。
- “返回跳转前”返回准确段落，并在离开、重启后保持一致。
- 搜索/书签回看不会意外改写正式进度；选择“从这里继续”才提交该回看位置。
- 加载失败时仍可继续原位置，不写入尚未成功打开的位置。

### C. 缩短阅读中的设置路径（R3、R4）

沿用现有纸页/墨色视觉体系，将快速外观调整整理为紧凑底部面板。首屏优先放字号、常用主题/夜间切换、亮度与跟随系统；行距、段距、缩进、字体和翻页动画等仍可通过更多设置访问。作用范围保留清晰但紧凑的当前书籍/全局选择。

快速设置沿用草稿预览、保存、取消的语义，让未遮挡的正文反映调整效果；一次保存提交，取消恢复。阅读内目录、菜单与设置面板按当前阅读主题配色，避免深色正文中突然出现大片亮色面板。

菜单移除短时自动收起：用户点击正文空白区域、开始翻页或按返回时关闭；点击菜单项进入相应功能。触摸正文文字时仍尊重既有选择/复制交互。

验收：

- 本次测试的手机尺寸、默认字体下，字号、夜间主题、亮度不滚动即可操作；较大系统字体下控件仍可到达。
- 改字号或主题时能看见正文预览；保存后生效且续读位置稳定，取消恢复原设置。
- 受影响回归：既有全局和当前书籍作用范围与界面提示一致，既有亮度跟随系统/自定义切换正常；这些能力无需作为新功能重做。
- 深色阅读下打开菜单、目录、快速设置，均使用可读的深色表面；原有主题与完整设置继续可达。
- 主动打开菜单后等待 10 秒仍可操作；点击正文、翻页、返回均可合理关闭，不把菜单操作当成翻页。

### D. 导入成功直接开始阅读（R5）

导入成功结果增加“开始阅读”主操作，使用已经完成入库的书籍身份打开阅读页；编辑书名作者作为次要操作。主目标是闭合本轮已复现的单本导入路径。失败或仍在处理中的项目不显示虚假的阅读入口；不为这项按钮改动扩展重复导入流程。

验收：

- 单本导入完成后一次点击进入正文，不经过返回书架和再次找书。
- 编辑信息操作继续可用。
- 若共享结果组件或导航改动影响批量导入、后台任务、失败重试或重复书籍处理，针对受影响路径补回归，确认原有流程没有中断。

## 验证与交付方式

只执行新增/修改代码及直接受影响的测试：A 聚焦分页/渲染/位置映射，B 聚焦导航/进度持久化，C 聚焦设置草稿与菜单交互，D 聚焦导入结果到阅读的导航。设备使用现有 API 37 16 KB 模拟器；本轮 1.0.0 Debug 体验不能替代后续修复包或 Release 的验证。

每一步先保留可重复的失败证据，再以同一场景对照修复结果。公开夹具继续复用本轮小说；私人输入按实际改动风险选择，不为纯菜单或按钮修改追加长篇回归。已更新本计划状态、当前任务与相关能力文档；开发验证包使用 `versionName = 1.0.1`、`versionCode = 9`，Debug 安装名追加 `-debug`。
