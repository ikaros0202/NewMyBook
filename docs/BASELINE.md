## 产品定位

纯离线、只读入本地 TXT 的 Android 阅读器。核心体验是快速找到书、沉浸阅读和可靠续读；书库整理、统计、个性化与备份服务于这一目标。无账号、广告、分析上报、云同步或在线书源。用户原始文件永不修改，私人资料不进入公开源码或证据。

## 当前能力

| 场景 | 当前实现 |
|---|---|
| 导入 | 系统文件选择器、实际读取上限 50 MiB、编码分析与确认、重复书籍处理、本地私有副本、任务状态与失败恢复 |
| 书库 | 默认首页为书架；标题/作者/系列搜索、阅读状态筛选、排序、作者/系列/集合、批量整理和自定义封面；三列网格为默认，可记住两列/四列/紧凑列表；搜索结果进入选择模式会先返回书架并显示选择栏；书架移除书卡进度条，使用更大的书封保持书籍识别 |
| 阅读 | 默认全屏沉浸；等长排版副本处理空白与缩进，原文用于选择/复制；章节起点是分页边界，标题参与测量；保存稳定文本位置，布局变化后恢复；目录选章和按当前版式按需生成的全书页码用于定位 |
| 阅读工具 | 目录、正文搜索、书签、高亮、批注、笔记、设备 TTS、自动翻页和定时停止；顶部返回/书名/书签/更多，底部目录/搜索/朗读/外观/笔记 |
| 个性化 | 高频快速设置与完整设置；快速入口提供作用域、字号、五种主题和全局亮度，“更多设置”保留字体、行/段距、缩进、翻页方式与主题计划，支持全局及单书范围 |
| 统计 | 本地有效阅读时长与书籍统计，日/周/月切换；单书统计可从顶部返回，系统返回回到全部统计；图表固定 184dp 视口，长周期合并为最多七个连续日期桶；有会话但无有效时长时明确提示 |
| 数据携带 | 备份页按“整个书架”和“笔记与单书”列出 Markdown/JSON 批注导出、完整备份/恢复和单书接力包；用户自行选择输出位置、保管和传输文件 |

根页面为书架、统计、设置；手机使用图标底栏，宽屏使用带文字的导航栏。具体尺寸和视觉角色见[设计系统](../design-system/xinyue/MASTER.md)。

## 1.0.1 继承能力与当前 1.0.2 Debug 行为

1.0.0 起始统一基线上的 1.0.1 连续阅读修复继续作为当前能力：

- **分页末行。** 页面发布前按实际渲染片段复测末端，避免分配给当前页的正文末行在屏幕底部被截断。
- **目录直接续读。** 成功的目录选章直接提交为稳定续读位置；阅读菜单保留“返回跳转前”，可回到目录跳转前的位置。
- **紧凑快速设置与深色工具。** 高频字号、主题/夜间、亮度和作用域集中在紧凑快速设置中；阅读菜单、目录和设置面板跟随当前阅读主题使用可读的表面配色。
- **菜单无定时收起。** 主动打开的阅读菜单不会因短时等待自动消失，通过正文点击、翻页、返回或菜单操作关闭。
- **导入直接阅读。** 成功导入且拥有有效书籍身份时提供“开始阅读”，直接进入阅读页并保留导入结果返回路径。
- **目录定位。** “定位当前章节”会清除目录搜索并滚回当前章；搜索已经为空时重复点击也有效，见[后续修复记录](../qa/current/1.0.1/navigation-followup/README.md)。
- **自动翻页与定时停止。** 自动翻页提供 10/15/20/30/60 秒间隔，默认 20 秒；正文触摸按下、手势、打开菜单、进入后台、离开阅读页、书末或翻页失败时暂停，不追赶错过的间隔。定时停止提供 15/30/60 分钟，使用单调时间计时，后台仍继续计时；到期停止 TTS 和自动翻页、临时解除保持亮屏并提示当前进度不变。离开阅读页会取消定时，重新进入后需重新开启。

当前 1.0.2 Debug 在上述能力之上提供以下界面入口和状态反馈：

- **界面与书架。** 工具界面使用白色/中性灰表面、较轻字重与少量暖橙 `#B44C1C` 强调；书架封面已放大，书卡不显示进度条，阅读菜单、目录和设置面板在深色阅读时仍使用可读的主题表面。
- **快速/完整外观设置。** 快速设置只保留作用域、字号、五种主题、全局亮度和“更多设置”；字体、行距、段距、缩进、翻页等低频项在完整面板继续可达。快速和完整页面共享外观草稿，保存或取消才结束编辑。
- **阅读菜单与页码跳转。** 顶部更多菜单承载目录管理、页码跳转和触摸锁，底部保留目录/搜索/朗读/外观/笔记等高频操作。目录选章和按当前版式异步生成的实际全书页码都可用于定位；未完成索引时明确标注本章页码（窗口不完整时标注约值），完成后显示全书页码。取消或失败不改正文和稳定进度，成功的正式跳页提交稳定进度并保留“返回跳转前”。
- **书架和统计返回。** 搜索结果“选择”或长按会先关闭搜索再进入书架选择模式；统计页选中单书后顶部显示返回箭头，系统返回回到全部统计；有阅读会话但没有有效时长时显示“暂无有效阅读时长”，不伪装成没有记录。
- **备份功能列表。** 备份入口按“整个书架”和“笔记与单书”分组，提供导出备份、从备份恢复、全部批注导出、单书接力包导出与接收，文件仍通过系统选择器交接。

9 月 29 日定向批次为 16 项（9 项 JVM、7 项 UI），公开长篇完成 1200 页跨窗口跳转和重启续读，设备验证后台暂停以及定时到期解除亮屏且保留进度。9 月 30 日增加 3 项朗读定向方法，修复错误反馈和旧回调，并按用户确认使朗读与自动翻页互斥。用户认可朗读与定时通过，证据与设备边界见 [补充 QA](../qa/current/1.0.2/followup-2026-09-30/README.md)；其他检查继续并补齐三个页码/版式/书末手工场景及图库整理，见 [接续验收](../qa/current/1.0.2/remaining-2026-09-30/README.md)。当前 APK 身份以 QA 为准，本页不表示全量回归或 Release 通过。实施背景见 [1.0.2 UI 整理计划](plans/1.0.2-ui-refinement.md)。

## 实现与兼容事实

- 技术和模块以 [Gradle 配置](../settings.gradle.kts)、[依赖版本](../gradle/libs.versions.toml)及[架构](architecture/README.md)为准。当前采用 Kotlin、Compose、Navigation 3、Hilt、Room/Bundled SQLite 和 WorkManager。
- 数据库 schema 为 12；历史 schema 1–12 和迁移保留。版本重命名不重置数据库，不改变数据身份。
- 完整备份写出 `.xinyuebackup` v2，兼容读取 v1/v2；单书 `.xinyuehandoff` 为 v1。格式与文件所有权详见[备份契约](contracts/backup.md)。
- 1.0.2 本轮增加按当前版式按需生成全书页码、目录/页码正式跳转、自动翻页与定时停止的阅读页控制器和 UI 接线，并继续整理 UI 入口与交互反馈；全书页码在字体、版式或章节变化后失效并重新生成，取消或失败不改正文和稳定进度；稳定领域 API、数据库 schema、备份格式和文件所有权没有改变，不需要数据库或备份格式迁移。自动翻页、定时停止和全书页码索引是阅读会话内状态，不写入持久设置；离开阅读页后定时取消。
- 备份、接力及批注导出可能包含私人资料，文件不加密；TTS 把朗读文本交给设备引擎。用户可见边界见[隐私说明](PRIVACY.md)。
- `minSdk 26`、compile/target SDK 37 是构建配置；后续设备验证默认用现有 `XinYue_API37` 16 KB 模拟器。测试结论仅覆盖实际环境。
