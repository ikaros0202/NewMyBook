# 新阅 1.0.0 产品基线

建立日期：2026-09-29。1.0.0 是从当前完整软件继续维护的统一源码版本；构建配置为 `versionName = "1.0.0"`、`versionCode = 8`，应用 ID 仍为 `com.xinyue.reader`。本轮完成文档和版本命名整理，不改变阅读业务逻辑，不生成或发布新安装包。

过去的 V1.2–V1.7、V1.7 B 是开发阶段名称。它们已经合并为本页描述的当前产品，不再作为并行的当前需求。过去本地 0.1.6 安装包和 GitHub 0.1.4 发布物属于历史产物，不能代表当前 1.0.0 源码。

## 产品定位

纯离线、只读入本地 TXT 的 Android 阅读器。核心体验是快速找到书、沉浸阅读和可靠续读；书库整理、统计、个性化与备份服务于这一目标。无账号、广告、分析上报、云同步或在线书源。用户原始文件永不修改，私人资料不进入公开源码或证据。

## 当前能力

| 场景 | 当前实现 |
|---|---|
| 导入 | 系统文件选择器、实际读取上限 50 MiB、编码分析与确认、重复书籍处理、本地私有副本、任务状态与失败恢复 |
| 书库 | 默认首页为书架；标题/作者搜索、阅读状态筛选、排序、作者/系列/集合、批量整理和自定义封面；三列网格为默认，可记住两列/四列/紧凑列表 |
| 阅读 | 默认全屏沉浸；等长排版副本处理空白与缩进，原文用于选择/复制；章节起点是分页边界，标题参与测量；保存稳定文本位置，布局变化后恢复 |
| 阅读工具 | 目录、正文搜索、书签、高亮、批注、笔记、设备 TTS；顶部返回/书名/书签/更多，底部目录/搜索/朗读/外观/笔记 |
| 个性化 | 高频快速设置与完整设置；字体、字号、行/段距、缩进、翻页方式、主题和主题计划，支持全局及单书范围 |
| 统计 | 本地有效阅读时长与书籍统计，日/周/月切换；图表固定 184dp 视口，长周期合并为最多七个连续日期桶 |
| 数据携带 | Markdown/JSON 批注导出、完整备份/恢复、单书接力包；用户自行选择输出位置、保管和传输文件 |

当前 UI 使用“纸页索引”：暖纸白/墨色底色、砖红强调色、系统衬线标题、平面书封、轻量分隔线和目录式设置。根页面为书架、统计、设置；手机使用图标底栏，宽屏使用带文字的导航栏。具体尺寸和视觉角色见[设计系统](../design-system/xinyue/MASTER.md)。

## 实现与兼容事实

- 技术和模块以 [Gradle 配置](../settings.gradle.kts)、[依赖版本](../gradle/libs.versions.toml)及[架构](architecture/README.md)为准。当前采用 Kotlin、Compose、Navigation 3、Hilt、Room/Bundled SQLite 和 WorkManager。
- 数据库 schema 为 12；历史 schema 1–12 和迁移保留。版本重命名不重置数据库，不改变数据身份。
- 完整备份写出 `.xinyuebackup` v2，兼容读取 v1/v2；单书 `.xinyuehandoff` 为 v1。格式与文件所有权详见[备份契约](contracts/backup.md)。
- 备份、接力及批注导出可能包含私人资料，文件不加密；TTS 把朗读文本交给设备引擎。用户可见边界见[隐私说明](PRIVACY.md)。
- `minSdk 26`、compile/target SDK 37 是构建配置；后续设备验证默认用现有 `XinYue_API37` 16 KB 模拟器。测试结论仅覆盖实际环境。
