# 隐私说明

更新日期：2026-08-10

新阅是本地优先阅读器：

- 不要求注册或登录，不包含广告、统计、崩溃上报或用户画像 SDK。
- 应用不声明 `INTERNET` 权限，也不声明读取全部存储空间的权限。
- 用户通过 Android 系统文件选择器明确选择 TXT；导入内容、书籍信息、进度、章节、书签、标注、设置、主题、封面、字体和阅读统计保存在应用私有目录。
- 本地 `.xinyuebackup` 备份不加密。备份始终包含书库结构化数据、设置、进度、书签/标注和统计；用户可选择是否包含正文与导入字体。省略正文时不能靠该备份独立恢复新书，省略字体时恢复后会回退到可用字体。导出前应用会明确显示这些后果。
- Markdown/JSON 批注导出可能包含用户摘录、上下文和私人批注；普通书签默认不导出。文件只写入用户通过系统文件选择器指定的位置，应用不会上传或分析导出内容。
- 本地 `.xinyuehandoff` 接力包未加密，只包含一书的身份、进度、完成状态、书签/高亮/批注、单书设置、系列和集合关系；不包含全局设置、阅读统计、字体或其他书籍。接力包默认不含正文，只有用户显式勾选并确认风险后才包含该书正文；自定义字体设置在包内安全回退。
- 不含正文的接力包只能应用到正文 SHA-256 完全一致的既有书籍，找不到时不会创建空壳书或改动现有数据。外部批注导出、备份和接力文件均由用户自行传输、保管和删除。
- 备份的保存位置和恢复来源均由用户通过 Android 系统文件选择器选择。应用只在私有目录中创建有界暂存区、覆盖前快照和恢复日志，并在成功、失败、取消或启动恢复后清理；不会上传备份或保存外部文件 URI。
- 卸载应用通常会清除应用私有数据，但不会自动删除用户已保存到外部位置的备份文件。新阅不提供云同步，外部备份文件由用户自行保管和删除。
- 连续朗读调用用户设备上的 Android TTS 引擎，并向该引擎提交当前朗读文本。TTS 引擎是否联网及其数据处理方式由用户选择的引擎决定。
- WorkManager 仅用于本地导入、备份、恢复、接力和私有文件清理，不上传书籍或使用情况。

如不希望 TTS 引擎接触正文，请不要启动“朗读”。

## 开发与公开仓库

应用自动化测试使用合成或公开夹具。用户私人输入及其原始 UI XML、日志、截图、唯一文件指纹和脱敏前原件只保存在仓库外，不进入 GitHub。公开范围、归档步骤和上传前门禁见 `docs/PUBLIC_REPOSITORY_PRIVACY.md`。
