# 公开源码与私人资料

更新：2026-09-29。应用运行时的数据处理见 [隐私说明](PRIVACY.md)。本页用于准备公开源码，不是每次开发都要执行的检查清单。

## 新基线的公开范围

- 应用源码、资源、Gradle 配置、Wrapper、Room 历史 schema 和迁移。
- 正式单元/设备测试、可复用 QA 脚本、合成或允许公开的 TXT 夹具。
- 当前 README、产品基线、架构/契约、设计规范和不含私人信息的任务记录。
- 不含凭据和具体个人路径的环境示例。

本地 `archive/` 保存旧规格和原始历史证据；`dist/` 保存旧交付；旧 QA 图片、XML、录屏和暂存包留在本机，不进入新源码历史。`.gitignore` 定义默认排除范围，公开前仍检查实际文件集。历史脚本的版本化名称只表示来源，不代表新基线需要重跑旧门禁。

## 私人资料

私人 TXT、字体、备份及其正文、文件名、路径、唯一指纹、原始 XML、日志和截图保存在仓库外的 `XINYUE_PRIVATE_QA_ROOT`。凭据、签名密钥、Cookie 和访问令牌不进入项目文档或公开文件；本机 SDK 配置等通过被忽略的本地配置或环境变量提供。

若处理既有私人来源资料，先在仓库外保存并校验原件，再生成只包含必要结论的脱敏记录。无法可靠脱敏的内容不公开。

## 上传前检查

对实际待公开文件执行检查，私人标记清单由仓库外的 `XINYUE_PRIVATE_DENYLIST` 提供：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\verify-public-repo.ps1 -PrivateDenylistPath $env:XINYUE_PRIVATE_DENYLIST
```

脚本通过 Git 文件清单检查凭据、个人目录、私人标记、归档条目和文件大小；不输出命中的敏感原文。它不会审核图片内容。若上传图片，单独目视复核；录屏、附件等也按实际内容检查，不把自动扫描通过当成隐私保证。

上传后核对远端提交与本地文件集。APK/AAB 发布属于另一个交付动作，需要单独验证产物版本、签名、权限与安装结果；当前 1.0.0 仅建立源码基线。
