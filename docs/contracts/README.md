# 新阅代码契约路由

> 状态：当前实现（基线 1.0.0）
> 用途：只选择当前编码任务需要的一类契约，不在这里展开全部接口。  
> 真相优先级：Kotlin 接口和类型是签名真相源；实现与测试定义可观察行为。

## 何时读取

- 了解项目、讨论需求、编写自然语言设计或制定高层计划时，不读本目录。
- 已经确定要修改的能力并准备写代码时，先从下表选择一个能力页。
- 只有任务确实跨越多个能力边界时，才增加第二个能力页。
- 进入能力页后，只读取它列出的相关接口、实现、调用方和代表性测试，不扫描同目录其他接口。

## 选择一个能力页

| 当前任务 | 只读这个入口 |
|---|---|
| 书架、书籍元数据、进度、多集合、系列、封面、统计 | [`library.md`](library.md) |
| 阅读、分页、章节、书签、标注、当前书批注导出、设置、主题、字体 | [`reader.md`](reader.md) |
| TXT 导入、私有正文、编码分析、全文搜索、索引与正文哈希身份 | [`import-search.md`](import-search.md) |
| 完整备份、全部批注导出、接力归档、冲突预览、恢复、回滚 | [`backup.md`](backup.md) |

跨模块调用顺序先查 [`../architecture/FLOWS.md`](../architecture/FLOWS.md) 的相关小节。不要从历史实施计划复制接口；计划保存当时的设计意图，接口可能已经在实现中演化。

## 所有能力共同遵守

- 不在 Markdown 中复制完整 Kotlin 签名。
- 改签名前搜索相关实现、调用方、测试替身和序列化模型。
- 改变取消、错误、幂等性、事务、所有权或 `Flow` 语义时，即使签名不变，也要更新接口 KDoc、相关能力页和测试。
- 纯内部 helper 或实现重排且契约未变时，不更新契约文档。
