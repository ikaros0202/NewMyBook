# 1.0.2 接续收尾

日期：2026-09-30。用户接受现有视觉作为继续细化的基础，确认朗读与自动翻页互斥；用户随后澄清朗读和定时两项认可通过，只停止这两项后续测试，其他定向检查继续。此前把范围理解为整轮停止是主代理误解，现已更正。本页记录该批朗读修复和实际清理，没有全量回归、提交、上传或发布。

## 本次改动

- 朗读初始化失败、中文语音缺失、系统合成失败会结束朗读状态并提示原因，不再显示正在朗读却没有反馈。
- 中文不可用时不静默回退其它语言；系统返回的中文 voice 明确需要联网时，优先选择标记为已安装的离线中文 voice，没有可用选项则提示安装离线语音。
- 系统完成/错误回调在主线程核对 utterance ID，停止或替换后的旧回调不能影响新任务。中文语音安装后，再次点击朗读可重新检查；引擎本身初始化失败时仍需重开阅读器。
- 开始自动翻页会停止朗读并清除下一页请求；开始朗读继续暂停自动翻页。
- `docs/DEVELOPMENT.md` 缩为 16 行少量开发基线，移除过时界面、工具链配方和固定开发流程，关联入口已同步。
