QA 统一在项目内组织：`qa/` 保存可公开的脚本、合成夹具和验收结论；`private-local/qa/` 保存本机私人输入、原始证据和审查日志，由 Git 忽略并排除在公开交付之外。无需再将私人回归资料放在仓库外。

源码提交只包含当前 QA 的 Markdown 结论。原始截图、音频、XML、日志、JSON 和 APK 保留在本机，文档中指向这些附件的链接仅在拥有对应本机资料时可用；源码公开不代表附件公开。
