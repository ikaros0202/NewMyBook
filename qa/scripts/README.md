# 模拟器 TXT 准备与任务收尾

这是代理执行验证的操作参考，不增加应用的功能门禁。用户指出的耗时来自反复找文件和点选；应用导入性能不在这次修改范围内。只验证当次改动及直接影响，已通过的功能不默认重测。

旧版 `run-v1.2-device-matrix.ps1`、`run-v1.2-accessibility-matrix.ps1` 和 `run-v1.6-api37-structured-txt.ps1` 的验收包使用正式 application ID。这三个入口现会在任何设备修改前检查全部 Android 用户（包括已停止用户与卸载后保留的数据）；发现正式包或验收测试包便拒绝执行，安装时也不使用覆盖选项。它们仅适用于没有这些包及数据的一次性验收设备。日常回归继续使用下面的固定公开测试用户流程，不能为运行旧脚本而清空现有用户。

直接运行 benchmark 的 `ReleaseSelectionTest` 也不再清空书库：它要求当前用户是已有的 `NewMyBook_Public_QA`，复用公开 `sample-novel`，每次用唯一的笔记内容定位本次记录。须先在该公开用户准备对应非 Debug 包及 `qa/sample-novel.txt`；不能为此覆盖其他用户的正式安装包。

## 一次准备，后续复用

使用当前已安装 Debug 包的 `XinYue_API37`。启动后先确认模拟器窗口在屏幕内，再运行：

```powershell
python qa/scripts/public-reader-session.py prepare
```

辅助脚本按名称识别 `NewMyBook_Public_QA` 公开测试用户，固定复用同一个，不依赖历史用户编号、不每轮删除重建。当前用户编号为 17；代码按名称发现实际编号，不硬编码 17。首次准备等待用户和文件服务就绪，将仓库中的公开 UTF-8 样例送入 Downloads，通过系统文件选择器直接点选确定文件，处理编码确认并核对导入成功。默认样例是 `qa/current/1.0.2/fixtures/bookpage-long.txt`，不是私人小说。

这个入口只准备公开样例；私人回归资料留在仓库外，证据采集前单独核对隐私范围。

后续运行先核对已有书籍，存在就复用，省去文件传输和导入点选。需要验证导入本身、清空状态或其它编码时，由当次任务选择独立场景；准备流程不代替功能验收，也不自动清空书库。

脚本有阶段和超时限制。失败时先看返回的阶段及公开诊断，修正对应问题后重试，不反复打开文件选择器寻找相似文件。设备串号与 ADB 路径可显式指定，完整参数见 `--help`。

可信复用同时核对实际书名和本机 `%LOCALAPPDATA%/NewMyBookQA/` 下的成功证明（用户、样例哈希等）。同名书缺少匹配证明时明确停止，避免误用其它内容。每次阶段记录默认保存到 `qa/current/public-reader-session/`，可用 `--output-dir` 指定当次证据目录。[2026-09-30 验证记录](../current/1.0.2/workflow-2026-09-30/README.md)保留首次修复与复用、关闭结果。

## 每次任务结束

停止测试和本次辅助进程，完成证据与未完成项记录，然后运行：

```powershell
python qa/scripts/public-reader-session.py stop
```

该入口切回主用户 0、停止公开测试用户并正常关闭指定项目模拟器；保留公开书库供下次复用，不卸载应用或清空用户数据。再确认模拟器进程和窗口已退出，关闭本次打开的临时浏览器标签、终端和预览；无关的用户原有窗口保留。

模拟器退出可能把 `emulator-user.ini` 的缩放重写为 `-1`。退出后检查窗口相关配置；当前屏幕可使用位置 `(100,100)`、缩放 `0.3`。只修复窗口键，下一次启动仍要检查实际可见性。
