# 新阅 · XinYue Reader

新阅是一款纯离线的 Android TXT 阅读器，围绕本地书库、沉浸阅读和可靠续读设计。没有账号、广告、分析上报、云同步或在线书源。

**1.0.0 是统一起始基线；1.0.1 的连续阅读修复作为继承能力保留；当前版本为 1.0.2（versionCode 10）。** 1.0.0 以现有完整软件为起点，统一了过去多轮迭代的产品与文档命名。2026-10-11 本地 Release 构建已通过，当前源码提交 GitHub；本轮交付记录见 [Release 构建记录](qa/current/1.0.2/release-2026-10-11/README.md)，此前定向验证见 [1.0.2 QA 记录](qa/current/1.0.2/README.md)。

## 已有能力

- 本地 TXT 导入：系统文件选择器、编码识别与确认、重复处理，单文件实际读取上限 50 MiB；保留用户原始文件；成功结果可直接“开始阅读”。
- 书库管理：书名/作者搜索、状态筛选、排序、作者/系列/集合、多选管理、自定义封面，以及可记住的 2/3/4 列网格和紧凑列表；当前书架移除书卡进度条，使用更大的精致书封强化书籍识别。
- 沉浸阅读：结构化段落与章节标题、连续分页、目录直接续读并可从阅读菜单返回跳转前位置、稳定进度、正文搜索、选择复制、书签、高亮、批注、设备 TTS、自动翻页和定时停止。
- 个性化与数据：紧凑快速设置与完整阅读设置、字体和主题、本地阅读统计、Markdown/JSON 批注导出、完整备份恢复和单书接力。

备份与接力文件不加密，由用户自行保管。TTS 使用设备上的引擎，该引擎的数据处理方式由其自身决定。详情见[隐私说明](docs/PRIVACY.md)。

## 当前 1.0.2 Debug 行为（未发布）

1.0.1 的连续阅读修复作为当前版本的基础能力：

- 分页末行在页面发布前按实际渲染片段复测，避免正文末行被底部裁切。
- 目录选章直接成为稳定续读位置，阅读菜单保留返回跳转前位置的入口。
- 快速设置收拢高频字号、主题/夜间、亮度和作用域；阅读菜单、目录与设置面板在深色阅读下使用可读的深色工具表面。
- 阅读菜单取消短时自动收起，等待用户明确操作。
- 导入成功结果提供“开始阅读”，直接打开已入库书籍。

1.0.2 在此基础上整理当前界面入口和状态反馈：

- 应用工具界面使用白色/中性灰表面、较轻的系统 `Medium` 字重和少量暖橙强调色 `#B44C1C`；书架使用更大的书封，书卡不显示进度条。
- 快速设置集中作用域、字号、五种主题、全局亮度和“更多设置”；行距、段距、缩进、字体和其他低频能力保留在完整设置面板，编辑仍使用同一份草稿并由保存/取消提交。
- 阅读菜单按顶部导航与更多操作、底部高频操作重新合并；阅读位置通过目录选章或按当前版式异步生成的实际全书页码跳转处理。未完成时明确标注本章页码（窗口不完整时标注约值）；字体、版式或章节变化会使索引失效并重新生成。取消、失败和离开不会改变稳定进度，成功的正式跳页提交稳定进度并保留“返回跳转前”；该能力不改变数据库 schema。
- 阅读菜单的“更多”提供自动翻页和定时停止；自动翻页支持 10/15/20/30/60 秒，正文触摸、手势、菜单、后台和离开阅读页会暂停，定时停止在后台继续计时并到期停止 TTS 与自动翻页、临时解除保持亮屏，不修改持久设置。
- 书架搜索结果进入“选择”或长按选择后先退出搜索，再显示书架选择栏；统计选中单书时顶部有返回箭头，系统返回回到全部统计，只有会话但没有有效时长时显示明确说明。
- 备份页按“整个书架”和“笔记与单书”列出备份恢复、批注导出和单书接力功能，继续通过系统文件选择器完成文件交接。

本轮定向验证共 16 项（9 项 JVM、7 项 UI）。公开长篇已完成 1200 页跨窗口跳转和重启续读；真实设备已验证 10 秒自动翻页在后台暂停，以及 15 分钟定时到期后解除保持亮屏且进度不变。中文 TTS 实际发声和运行中的定时停止 TTS 尚未实机验证。最终验收结论和 APK 身份以 [1.0.2 QA 记录](qa/current/1.0.2/README.md)为准；本页不重复 APK 哈希，不表示全量回归或 Release 通过。实施背景见 [1.0.2 UI 整理计划](docs/plans/1.0.2-ui-refinement.md)。

## 构建与验证

使用 JDK 17 或兼容的更新版本、Android SDK 37 和项目自带 Gradle Wrapper。当前版本为 1.0.2 / versionCode 10；本轮 Release 产物身份以 [Release 构建记录](qa/current/1.0.2/release-2026-10-11/README.md)为准：

```powershell
.\gradlew.bat :app:assembleDebug --no-configuration-cache
adb install -r app\build\outputs\apk\debug\app-debug.apk
.\gradlew.bat :app:assembleRelease --no-configuration-cache
```

SDK 路径在本机 `local.properties` 或环境中配置。依赖版本以 [Gradle 版本目录](gradle/libs.versions.toml) 为准。`minSdk 26` 是构建声明；已有设备证据主要来自 API 37、16 KB 模拟器，不代表所有设备均已验证。

默认 Release 构建开启代码压缩与资源裁剪，未配置发布签名，因此输出 `app-release-unsigned.apk`；安装前需要签名。本机交付可使用调试证书签名并明确标注，不将密钥或 APK 提交到源码 Git 历史。

每次修改只验证新增/修改代码及其直接影响，不例行运行全量测试；私人长篇 TXT 按风险选择。少量现状与接续入口见[开发基线](docs/DEVELOPMENT.md)，具体开发安排由当次对话决定。
